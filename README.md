# TalentBridge Recruiting Website
TalentBridge is a two-page recruiting website prototype that introduces a recruiting company and connects candidates with employers.

## Features
- Linked pages for recruiters and candidates.
- Sections describing the company, services, vision, and values.
- Recruiter form for company details and hiring needs.
- Candidate form for contact information, experience, and career preferences.
- Responsive layout for desktop and mobile devices.

## Technologies
- HTML5
- CSS3

## Project Files
- `recruiters.html` — Recruiter introduction and hiring request form.
- `candidates.html` — Candidate introduction and profile form.
- `styles.css` — Shared styling for both pages.


## Limitations

This is a frontend prototype. Forms do not save or send information, and submission buttons are disabled. A backend and database are needed to process submissions.

## Future Improvements

- Connect forms to a backend and database.
- Add user accounts and authentication.
- Implement job listings and candidate matching.
